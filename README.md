# AutoParkApp
WPF-приложение для управления автопарком компании: транспортные средства, водители и рейсы. Работа с базой данных ведётся через Entity Framework (Database First, `.edmx`).
## Технологии
- C# / WPF (.NET Framework)
- Entity Framework (модель `AutoParkModel.edmx`)
- LINQ
- SQL Server

## Возможности
- Авторизация и регистрация водителей
- Просмотр списков транспортных средств, водителей и рейсов
- CRUD-операции для транспортных средств и водителей
- Регистрация рейса с выбором водителя и транспортного средства
- Автоматическое обновление статуса транспорта («Доступен» / «В рейсе» / «В ремонте»)
- История рейсов по транспортному средству и водителю
- Фильтрация рейсов по дате, транспорту и водителю
- Валидация данных в интерфейсе (формат гос. номера, обязательные поля)

### Дополнительно (на оценку 5)
- Сортировка транспорта по пробегу, году выпуска и другим параметрам
- Отчёт о суммарном пробеге каждого транспортного средства
- Бейдж о необходимости техобслуживания при достижении заданного пробега

## База данных
Используется БД `AutoParkDB` (SQL Server) с таблицами:

| Таблица    | Назначение                                                        |
|------------|-------------------------------------------------------------------|
| `Vehicles` | Транспорт: гос. номер, модель, производитель, год, пробег, статус |
| `Drivers`  | Водители: ФИО, номер ВУ, телефон, стаж, email, пароль             |
| `Routes`   | Рейсы: транспорт, водитель, даты, маршрут, расстояние             |

## Запуск
1. Создайте базу данных `AutoParkDB` в SQL Server.
2. Выполните SQL-скрипт создания таблиц и тестовых данных.
3. В `App.config` укажите свою строку подключения к серверу.
4. Откройте решение в Visual Studio, восстановите NuGet-пакеты.
5. Запустите проект (`F5`).
